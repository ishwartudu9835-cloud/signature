# Cowartu Email Signatures

Cowartu aur Ishwar Tudu ke email signatures.

## Files
- `index.html` - dono signatures ka menu
- `ishwar.html` - Ishwar Tudu ka signature
- `support.html` - Cowartu Support ka signature
- `images/` - icons, photo aur logo

## Kaise use karein
1. Repo ko GitHub Pages ya Cloudflare Pages par host karein.
2. Hosted link kholein (local file nahi), jaise `https://<aapka-link>/ishwar.html`.
3. "Signature Copy Karein" dabayein.
4. GoDaddy Email -> Settings -> Signature mein paste karke save karein.

Images hosted link se aati hain, isliye signature dusre ke email mein bhi dikhta hai.
Photo ya logo badalna ho to `images/` mein wahi naam ki nayi PNG daal dein.
