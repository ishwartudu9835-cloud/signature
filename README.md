# Cowartu Email Signatures

13 premium email signature templates, Ishwar Tudu aur Cowartu Support dono ke liye.

## Files
- `index.html` - saare templates (upar se Ishwar / Cowartu Support chuniye)
- `images/` - icons, photo aur logo

## Kaise use karein
1. Repo ko GitHub Pages ya Cloudflare Pages par host karein.
2. Hosted link kholein (local file nahi).
3. Pasand ka template dhundhein aur uske `Copy` button dabayein.
4. GoDaddy Email -> Settings -> Signature mein paste karke save karein.

## Badlav
- Phone, email ya link badalne ho to `index.html` ke upar `PROFILES` section mein badlein.
- Photo ya logo badalna ho to `images/` mein wahi naam ki nayi PNG daal dein.
